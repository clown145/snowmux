1. 三键与快捷操作

《SnowMux 使用说明书》适用于运行 SnowMux 社区固件的雪酥·3。装好 SD 卡、开机选好语言后，可以先用这本书练习翻页。

  • 上键、下键：在列表中移动；在阅读正文中翻页。
  • 短按确认：打开当前选中的项目；在正文中打开阅读菜单。
  • 长按确认：默认返回上一层，或取消当前操作。

在首页、文件等带标签栏的页面，长按确认可回到标签栏。在文件夹内先逐级返回。标签栏获得焦点后，用上下键换标签，短按确认进入。

双击确认打开悬浮快捷栏

在主标签页或阅读正文，快速连按两下确认键（间隔约 0.3 秒以内）。悬浮窗弹出后，用上下键选择，短按确认执行，长按确认关闭。常用项有「休眠」「夜间模式」「刷新屏幕」和「阅读方向」。

在阅读正文中，双击确认后再短按一次，就能显示或隐藏状态栏并回到正文。设备会记住你的选择。

有专属操作时，它会出现在悬浮窗第一项。以下场景也可以双击确认：

  • 文件、书库：选中条目，可进入「文件操作」或「书库操作」。书库排序栏也能打开书库操作。
  • 书签、剪藏：选中条目，可打开「书签操作」或「删除剪藏」。
  • 最近阅读、阅读统计：选中书籍，可移除相应记录，书文件仍在。
  • OPDS 分页目录：选「目录翻页」，再选上一页、下一页、首页或末页。只显示服务器提供的方向。
  • 待机显示：选「设为休眠画面」，保存当前表盘。

选中已保存的 Wi-Fi、已安装插件或蓝牙翻页器的按键映射时，也可以双击确认，找到忘记网络、移除插件或清除按键映射的入口。阅读工具栏、选词等子页面有自己的按键操作，请看屏幕提示。

2. 阅读与排版

从「书库」或文件页选书，短按确认打开。默认上键翻上一页、下键翻下一页；需要反过来，可在「设置 → 操作 → 侧键布局(阅读器)」调整。

正文中短按确认可查看目录、文字设置、书签或进度等选项。菜单的样式随主题变化。EPUB 列表式阅读菜单有「本页脚注」时，选它即可查看当前页的脚注，长按确认可回到正文。

EPUB 长按快捷键：在「设置 → 操作 → 长按按键行为」可把长按翻页键设成跳章或切换方向。「长按菜单功能」则可把正文里的长按确认改成书签、查词、创建剪藏或同步；关闭后恢复默认返回操作。

从阅读菜单或「设置 → 阅读器 → 文字设置」调整字体、字号、行距和页边距。文字设置的列表到了首项或末项，再向外按一次即可回到标签栏。用上下键切换标签，短按确认进入。

「设置 → 阅读器」也可管理字体和离线词典。首次打开书籍或改动排版后，设备可能需要重新分页。

3. 把书传到雪酥

USB 传书

进入「应用 → 文件传输 → USB 磁盘」，用支持数据传输的 USB 线连接电脑。把书复制到电脑识别出的 SD 卡，例如 /Books/ 文件夹。传完先在电脑安全弹出磁盘，再回到设备打开图书。

Wi-Fi 传书

在「文件传输」选择「加入网络」或「创建热点」，按屏幕指引连接。用手机或电脑打开屏幕显示的网页地址，在网页上传文件。传输服务没有登录验证，请在可信网络上使用，传完退出。

常用阅读格式有 EPUB、TXT 和 XTC／XTCH。也可打开不加密、源文件不超过 4 MiB 的 MOBI／AZW3，以及 DOCX。DOCX 会重排正文和支持的内嵌图片，复杂页面可能与 Word 中的版式不同。

4. 配网与手机输入

连接路由器时，进入「设置 → 连接 → 热点配网」。用手机扫屏幕上的二维码加入临时热点；也可按任一侧键查看热点密码。如果没有自动弹出网页，就用浏览器打开设备显示的地址。

在网页选择家里的 2.4 GHz Wi-Fi，输入密码并提交。等雪酥提示连接成功后再退出。保存过的网络会供后续联网功能使用。

新增或编辑 OPDS 服务器、填写 KOReader 同步账号或地址，以及输入目录搜索词、解锁口令时，也会打开类似的手机表单。按屏幕提示连热点、在网页填好并提交，再回到雪酥短按确认继续。长按确认可退出未提交的表单。

5. 书库与原厂阅读记录

传完书，可以先在文件页按目录查找。如果文件页能看到新书、书库里还没有，在书库选中一本书或将焦点移到排序栏，双击确认，选择「书库操作 → 刷新书库」。书库显示「未排序」时，可直接在内容区双击确认。

选中文件后双击确认，从「文件操作」打开、移动或删除文件。删除前请核对书名。

原厂系统用过的 SD 卡，可在「设置 → 系统 → 导入原厂最近阅读」追加仍在卡上的图书。没有 SnowMux 进度的书，首次打开会尝试按原厂记录的百分比定位。已有 SnowMux 进度的书会保留原来的位置。

6. 应用与休眠表盘

哪些应用可以显示

新设置默认显示书库、文件传输、微信读书、AirPage、阅读统计和待机显示。添加 OPDS 服务器后，应用菜单才会显示 OPDS 浏览器。

丑丑头像、Buddy 和电子木鱼默认隐藏。进入「设置 → 系统 → 隐藏应用」，选中一项，短按确认切换为「开」，长按确认退出并保存。

数独、五子棋、推箱子、中国象棋、扫雷、2048、像素大战和计算器需要触屏或独立左右键，雪酥·3 不提供这些应用入口。

休眠与表盘

双击确认，从快捷栏选择「休眠」，或者进入「设置 → 系统 → 休眠」。休眠后短按确认唤醒。在「设置 → 显示 → 休眠时间」可以调整空闲多久后自动休眠。

在「应用 → 待机显示」短按上下键，切换手绘时钟、传统日历、月历网格、报刊排印和国庆·烟花。短按确认切换反色，长按确认退出。双击确认，选「设为休眠画面」；也可从「设置 → 显示 → 休眠画面」直接选择。

选择时钟表盘前，请到「设置 → 系统 → 日期与时间」校准时间。手绘时钟和三款原厂风格的表盘休眠时按分钟刷新；传统日历在本地日期变化时更新。

7. 更新 SnowMux

如果当前版本有「设置 → 系统 → 检查更新」，可联网按提示更新 SnowMux。没有这个入口时，请用电脑访问 SnowMux 刷机站：clown145.github.io/snowmux/。

请保留首次安装时下载的整机备份。网页和设备内更新都写入另一槽，后续更新可能覆盖原厂固件。更新期间保持电量充足，勿断电或强制重启。

如果「检查更新」中有「恢复原厂固件」，可以按提示联网下载安装原厂应用。要恢复整片 Flash，请使用首次安装时保存的本机备份。

8. 常见问题

墨水屏有残影：双击确认，在快捷栏选「刷新屏幕」。也可在「设置 → 显示 → 刷新频率」调整完整刷新的间隔。

书打不开或字不全：先确认文件已完整复制、格式受支持。只有部分字符显示为空白时，试着换用覆盖这些字符的字体。

手机连热点后打不开网页：确认手机仍连接雪酥的临时热点。手机提示该 Wi-Fi 无互联网时，选择继续使用，再在浏览器输入设备屏幕上的地址。

SD 卡报错或提示过慢：先备份书和 /.crosspoint/，再检查或更换 SD 卡。这个目录里有阅读进度和设置，清理前请先备份。
