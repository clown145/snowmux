刷机帮助

        

          

            安卓手机怎么刷
            

              用安卓 Chrome 打开本页，用支持数据传输的 USB 线或 OTG 转接头连接雪酥，按确认键唤醒。
              点「连接设备」，选择 USB JTAG/serial debug unit，并在安卓弹窗里允许访问。
              备份和刷机期间保持页面在前台、屏幕亮着。
            

          

          

            浏览器没有发现设备
            

              确认雪酥已唤醒并退出 USB 磁盘模式。安卓手机如果有 OTG 开关，请打开后重连。
              电脑上请用 Chrome 或 Edge，并关闭占用串口的程序。iPhone 和 iPad 可下载固件，无法直接刷机。
            

          

          

            刷机会写到哪里
            

              本站检查芯片、分区、原厂应用和启动记录，仅将应用写到
              OTA1。首次安装在读回校验成功后切换启动槽，保留原厂 OTA0、原厂分区表和 NVS。
            

          

          

            备份存在哪里
            

              浏览器将 16 MiB Flash
              备份保存到浏览器的下载目录。安卓上读取完成后，点「下载 Flash 备份」。备份可能包含设备数据，请妥善保存。
